# English Adventure

小学校入学前のお子さんが、毎日3分ほど英語を声に出して遊ぶための、インストール不要のWebアプリです。

## 使い方

`index.html` を Safari または Chrome で開いてください。iPhone / iPad では共有メニューから「ホーム画面に追加」を選ぶと、アプリのように起動できます。

## 入っているもの

- 今日のひとこと：お手本の音声と発話チャレンジ
- えいごクイズ：絵を見て単語を選ぶミニゲーム
- おしゃべり：キャラクターとの短い会話
- 連続記録、ほし、ごほうび
- おうちの人向けの今日の振り返り

音声認識に対応しているブラウザではマイクで聞き取ります。非対応の場合も、発話できたかを本人が確認して先へ進める設計です。進捗はその端末のブラウザ内に保存されます。
